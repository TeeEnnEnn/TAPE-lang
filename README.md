# TAPE-lang
Theo's Awesome Programming Experience

TAPE is a memory managed, applications language which aims to provide clear syntax and high performance.


## Getting Started

TAPE only has one dependency:
- Zig (v0.17+) 

Ensure you have zig installed on your system, then run:
```sh
zig build
```

this will build the `TAPE_lang` executable

For running zig tests:
```sh
zig build test
```

For running TAPE's example scripts and tests:
```sh
./scripts/run_examples.sh
```

Check `examples/` for a examples of all the language features in use
You'll notice that the syntax resembles Zig quite a bit.
